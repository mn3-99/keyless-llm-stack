Keyless LLM Stack zero API keys

بوابة “OpenAI-compatible” تعتمد مزوّدين عامين بلا مفاتيح، بلا تسجيل، بلا أي مصادقة منك. فُحصت حياً (خط multicscript) على مئات المسارات.

دائم ومستضاف فعلاً: Kilo Gateway

نقطة API معلومة، مفتوحة، لتطبيقنا وأي تطبيق خارجي دون حساب:

BASE  https://api.kilo.ai/api/gateway
KEY   (بدون أي مفتاح)
MODEL kilo-auto/free      # اختيار ذكي تلقائي
      openrouter/free     # مجمع نماذج OpenRouter المجانية
      nvidia/nemotron-3-ultra-550b-a55b:free

curl https://api.kilo.ai/api/gateway/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"kilo-auto/free","messages":[{"role":"user","content":"ما هو 17*23؟"}]}'

curl https://api.kilo.ai/api/gateway/models   # كل النماذج

من أي مشروع خارجي

Python

from openai import OpenAI
client = OpenAI(base_url="https://api.kilo.ai/api/gateway", api_key="x")
r = client.chat.completions.create(model="openrouter/free",
      messages=[{"role":"user","content":"11*13?"}])
print(r.choices[0].message.content)

Node.js

const r = await fetch("https://api.kilo.ai/api/gateway/chat/completions", {
  method: "POST",
  headers: {"Content-Type":"application/json"},
  body: JSON.stringify({model:"openrouter/free",
    messages:[{role:"user",content:"11*13?"}]})
});
console.log((await r.json()).choices[0].message.content);
